# Gemini Project – Astronaut Health Monitoring

A React-based, government-style astronaut health and wellness monitoring frontend inspired by the UX4G design system.

## Tech stack

- React 18
- React Router DOM v6
- CSS (custom, UX4G-style)

## Folder structure

- `public/` – static files (`index.html`, favicon)
- `src/index.js` – React entry point
- `src/App.js` – layout + page progress
- `src/routes.js` – route configuration
- `src/pages/` – main pages (Home, Details, HealthMonitor, ChatbotPage)
- `src/components/` – reusable pieces (Intro, DetailsForm, HealthOptions, Chatbot)
- `src/services/` – placeholders for API and encryption logic
- `src/App.css` – global styling
